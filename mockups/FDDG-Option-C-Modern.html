Core Services

How we examine a digital document

Each service starts with a plain-language summary. Select “What we examine” for the technical detail.

Metadata & Origins

Deep metadata extraction & analysis

We extract the hidden information inside a file, beyond what your computer shows, and explain what it reveals.

  • PDF Info dictionary and XMP metadata
  • Office document properties (core and app)
  • Image EXIF / IPTC and video container metadata
  • Cross-checks between metadata stores that should agree

Software & version identification

We identify the programs, and their versions, that created a document or worked on it afterward.

  • Producer, Creator, and CreatorTool fields
  • Structural fingerprints specific to each program
  • Release dates compared with the document’s stated date

Date & timestamp analysis

We compare the dates in the metadata, the dates printed on the page, and the timestamps embedded in the file’s binary data.

  • Creation, modification, and print dates
  • Internal container timestamps (ZIP / OLE)
  • Edit-history entries and time-zone offsets
History & Integrity

Revision history & recovery

We trace earlier versions of a file and recover deleted or replaced content that the file still holds.

  • PDF incremental updates (earlier saved states)
  • Word revision IDs and tracked changes
  • Orphaned objects and legacy fast-save data

Digital signature & cryptographic analysis

We verify digital signatures and determine whether the document changed after it was signed.

  • Signature containers and signed byte ranges
  • Certificate chains and trusted timestamps
  • Changes made after the signature was applied

Font analysis & date consistency

We check whether the fonts in a digital document existed on the date the document claims.

  • Embedded font names, subsets, and versions
  • Font release histories
  • Glyphs that were added in later font versions
Structure & Content

Composition & structure analysis

When one file combines many, such as a PDF declaration with multiple exhibits, we examine each part on its own, because each can carry its own deep metadata.

  • Page-by-page source identification
  • Component-level metadata and producers
  • Where and when each part was assembled

Embedded object, image & duplicate asset analysis

We examine images and objects inside a document and find the same assets wherever else they appear.

  • Embedded images and their own metadata
  • Embedded Office objects and thumbnails
  • Exact and visual-similarity matching

Scanned document & OCR analysis

We examine how a scan was produced and whether its searchable text matches what the page shows.

  • Scanner and device signatures
  • Hidden OCR text compared with the page image
  • Image compression and processing traces

Byte-level file examination

We examine the raw structure of a file to find traces that ordinary software never displays.

  • File signatures and internal offsets
  • Data appended after the end of the file
  • Malformed or inconsistent structures
Email & Case-Wide

Email header, routing & attachment analysis

We trace an email’s path between servers, check its authentication, and examine its attachments.

  • Received headers and Message-ID
  • DKIM, SPF, and DMARC results
  • Attachment metadata and hashes

Case-wide correlation & duplicate detection

We compare documents across one or more productions to find duplicates, shared origins, and inconsistencies.

  • Exact and near-duplicate matching
  • Shared document identifiers across files
  • One timeline for the entire production
